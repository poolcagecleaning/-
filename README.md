## Design

- **Theme:** Aurora Gradient — deep ocean blues, teal and violet aurora glows, solid gradient background (no transparency leaks on any device)
- **Fonts:** DM Serif Display (headings) + Inter (body)
- **Colors:** Solid deep-blue base (#0f2027 → #2c5364), teal accent (#3ecfcf), mint highlights (#a8edea)
- **No phone number or call button** — intentionally excluded per brief
- **No external ads or tracking scripts**
